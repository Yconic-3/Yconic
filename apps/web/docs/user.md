# 사용자 화면 (/) — 소리벗

> 관리자 화면과 한 웹앱(`apps/web`)이다 (`docs/decisions/0004`). 사용자 화면 주소는 `/`이다.
> 아래 구조의 `components/`, `lib/`는 `src/user/` 아래에 있고, 페이지는 `src/app/(user)/`에 있다.

**말로 찾고, 듣고 따라 하는 운동.** 시각장애인과 일반 사용자가 말로 운동을 찾고, 단계별 음성 안내를 들으며 운동한다.
로그인한 회원은 운동 영상을 올려 음성 안내를 만들고 검수를 요청할 수도 있다 (콘텐츠 올리기).
화면은 디자인 시안 D(소리벗 · 다크 고대비)를 따른다 (`docs/decisions/0007`).

콘텐츠는 공개된 영상과 단계별 음성 안내다 (`docs/decisions/0002-영상-중심-콘텐츠-모델.md`).
앱은 영상(또는 시간)을 재생하다가 단계가 시작될 때 그 단계의 안내를 읽어 준다.
'내 강의'에 등록한 강의의 동작이면 짧은 안내(`conciseGuide`)를, 아니면 자세한 안내(`voiceGuide`)를 읽는다.

## 실행

`apps/web/README.md`의 실행 순서를 따른다. 서버 없이 화면만 보려면 `NEXT_PUBLIC_API_MODE=mock`.

- 예시 콘텐츠에는 영상 파일이 없다. 이때는 영상 없이 시간만 흘려 단계 안내를 들려준다.
- 음성 인식은 Chrome 계열 브라우저에서 마이크를 허용해야 동작한다. 안 되는 환경에서는 "말 대신 글로 입력"으로 같은 기능을 쓴다.

## 화면 구조

모든 주소가 같은 틀(`components/assistant-app.tsx`)을 쓴다. 그래서 화면이 바뀌어도 마이크 듣기와 대화가 끊기지 않는다.

| 주소 | 화면 | 로그인 |
| --- | --- | --- |
| `/` | 운동하기 홈: 로그인 안내, 운동 목록 | 필요 없음 |
| `/exercises/{id}` | 운동 화면: 영상, 시작·다음·다시·이전, 주의할 자세, 전체 단계 | 필요 없음 |
| `/account` | 로그인 / 내 계정 | |
| `/courses` | 내 강의: 강사에게 배운 강의 고르기 | 필요 |
| `/my/contents` | 내 콘텐츠: 올린 콘텐츠와 검수·공개 상태 | 필요 |
| `/my/contents/new` | 새 콘텐츠 만들기: 영상 올리기 → AI 분석 | 필요 |
| `/my/contents/{id}` | 콘텐츠 확인: 화면에서만 전달되던 정보, 단계별 안내 고치기·미리 듣기, 검수 요청 | 필요 |

로그인이 필요한 화면은 로그인 전이면 안내와 "로그인하러 가기"를 보여 주고, 로그인 뒤 그 화면으로 돌아온다.

틀의 순서 (코드 순서 = 화면 순서 = 스크린리더 순서):

| 구역 | 내용 |
| --- | --- |
| 머리말 | 소리벗 이름, 화면 종류 탭(운동하기 / 콘텐츠 올리기), 로그인·로그아웃, 음성 안내 켜짐·꺼짐 |
| 제목 | 화면 종류 · 로그인 상태, 큰 제목 |
| 방금 안내 | 앱이 마지막으로 한 말(노란 테두리), 내가 한 말, 방금 안내 다시 듣기 |
| 화면 이동 | 이전 화면으로, 운동하기 홈으로 (홈이 아닐 때) |
| 본문 | 주소마다 다르다 (위 표) |
| 메뉴 | 운동하기: 로그인·내 계정, 운동 목록, 내 강의, 콘텐츠 올리기로 바꾸기 (관리자면 관리자 페이지). 콘텐츠 올리기: 내 콘텐츠, 새 콘텐츠, 운동하기로 바꾸기 |
| 음성 패널 | 큰 마이크 버튼, 상태, "이렇게 말해 보세요" 예시, 말 속도, 말 대신 글로 입력 |
| 음성 읽기 조작 | 읽는 동안 화면 아래에 붙는다. 읽기 잠시 멈춤 / 이어서 읽기 |
| 바닥글 | 소리벗 · 와이코닉. 모든 안내는 올린 사람이 확인하고 운영자가 검수한 뒤에만 공개된다 |

- 넓은 화면(961px 이상): 왼쪽 본문 + 오른쪽 음성 패널.
- 좁은 화면(960px 이하): 한 열. 마이크(와 읽기 잠시 멈춤)만 화면 맨 아래에 붙는다.

### 접근성 원칙 (바꿀 때 지킬 것)

- **읽는 순서 = 보이는 순서.** CSS로 순서를 바꾸지 않는다 (order, grid 재배치 금지).
- **상태는 글로.** 색만으로 알리지 않는다. 지금 화면에는 "(지금 화면)", 지금 단계에는 "(지금)"을 붙이고, 켜고 끄는 버튼은 `aria-pressed`를 쓴다.
- **노랑은 가장 중요한 조작과 '지금 여기'에만**, 하늘색은 보조 조작과 초점 표시에 쓴다.
- **말이 먼저.** 앱의 모든 응답은 소리로 먼저 나가고, '방금 안내'가 그 글이다. 음성 안내를 끄면 글로만 보여 주고, 스크린리더 알림 영역에도 넣는다.
- 화면이 바뀌면 맨 위로 올리고 제목으로 초점을 옮긴다. "본문으로 건너뛰기", "마이크로 건너뛰기" 링크가 있다.
- 색은 `src/app/globals.css`의 토큰만 쓴다. 글자는 바탕과 4.5:1 이상, 누를 수 있는 요소의 테두리는 3:1 이상이다.
- 터치 영역은 높이 56px 이상. 주요 버튼은 68~84px, 마이크는 128px(좁은 화면 96px)이다.
- 움직임을 줄이는 설정이면 버튼 눌림 효과를 끈다.

## 쓸 수 있는 말

| 말 | 동작 |
| --- | --- |
| "하체 운동 찾아줘", "스트레칭 찾아줘" | 분류나 태그로 목록 열기 |
| "스쿼트", "스쿼트 시작" | 운동 열기 / 열고 바로 시작 |
| "시작", "계속", "멈춰", "다음", "이전", "다시" | 운동 조작 |
| "느리게", "빠르게" | 말하기 속도 |
| "음성 안내 꺼", "음성 켜" | 음성 안내 켜기·끄기 |
| "음성 멈춰", "이어 읽어" | 읽던 말 잠시 멈춤·이어 읽기 |
| "로그인", "내 계정", "로그아웃" | 계정 |
| "콘텐츠 올리기", "새 콘텐츠", "운동하기" | 화면 종류 바꾸기 |
| "분석 시작" / "미리 듣기", "검수 요청" | 새 콘텐츠 만들기 / 콘텐츠 확인 화면에서 |
| "내 강의", "하체 강의 들었어", "코어 강의 안 들었어" | 내 강의 화면, 강의 등록·빼기 |
| "이전 화면", "홈" | 화면 이동 ("이전"만 말하면 이전 단계) |
| "도움말" | 쓸 수 있는 말 안내 |
| "아파요", "어지러워요", "숨이 차요" | **운동을 바로 멈추고** 쉬도록 안내 (다른 말보다 먼저 처리) |

위 표는 정해진 말이다. **사용자 AI 에이전트(`apps/user-agent`)가 켜져 있으면** "무릎에 무리 없는 하체 운동 있어?", "그거 할래"처럼
자연스러운 말과 앞 대화를 이어 받는 말도 알아듣는다 (`src/user/lib/agent.ts`, 결정 기록 0006).

- 위험 신호, 앱 명령(계정·음성 설정·화면 종류·내 강의), 운동 화면의 짧은 조작(8자 이하)은 에이전트를 거치지 않고 바로 처리한다 (`handleLocally`).
- 콘텐츠 올리기 화면에서는 에이전트를 쓰지 않는다. 그 화면의 말("분석 시작" 등)은 페이지가 먼저 처리한다 (`usePageCommands`).
- 에이전트가 꺼져 있거나 답하지 못하면 규칙(`src/user/lib/intent.ts`)으로 처리한다.

앱은 가진 콘텐츠 안에서만 답하고, 없는 운동 정보를 지어내지 않는다. 의료적 판단도 하지 않는다 (설계 문서 10장).

## 콘텐츠 올리기 흐름

1. 새 콘텐츠 만들기에서 운동 이름·분류·난이도를 적고 영상 파일을 고른 뒤 "분석 시작".
2. 영상을 올리고 AI 제작 작업이 진행된다 (단계별 진행 문구가 나온다).
3. 끝나면 콘텐츠 확인 화면으로 간다. 맨 위에 **화면에서만 전달되던 정보**(동작 방향, 신체 위치, 자막, 횟수)가 나온다.
4. 단계별 음성 안내를 고치고 미리 듣는다. "이렇게", "여기" 같은 표현이 있으면 "고쳐야 할 표현" 경고가 나온다.
5. "동작 설명이 정확하고 안전한지 직접 확인했습니다"에 표시하고 "검수 요청하기".
   시각 의존 표현이 남아 있거나 표시하지 않았으면 요청이 막힌다.
6. 운영자(승인권자)가 관리자 화면에서 검수·승인·공개한다. 올린 사람은 직접 공개할 수 없다.

## 구조

```
src/
├── app/(user)/
│   ├── login/                  # 로그인 (관리자 화면이 보내는 곳)
│   └── (assistant)/            # 틀 안의 페이지들: account, courses, my/contents …
├── user/components/
│   ├── assistant-app.tsx       # 틀: 머리말·방금 안내·메뉴·음성 패널, 운동하기 홈·운동 화면, 말 처리
│   ├── ui.tsx                  # 버튼·목록 버튼·구역·아이콘 (시안 D)
│   ├── login-form.tsx          # 로그인 양식과 체험용 계정
│   └── creator-ui.tsx          # 콘텐츠 상태 문구, 로그인 필요 안내
└── user/lib/
    ├── shell.tsx               # 틀과 페이지가 주고받는 것 (제목, 페이지 음성 명령, 내 강의)
    ├── api/                    # 공개 운동 (UserApi)
    ├── creator-api/            # 회원 콘텐츠 올리기 (서버 /me, 모의 구현) (테스트 있음)
    ├── courses-api.ts          # 내 강의 읽기·저장
    ├── agent.ts                # AI 에이전트에 말 보내기, 바로 처리할 말 고르기 (테스트 있음)
    ├── intent.ts               # 말 → 할 일, 규칙 기반 (테스트 있음)
    ├── player.ts               # 시각 ↔ 구간 계산, 세션 상태 (테스트 있음)
    ├── navigation.ts           # 운동하기 홈 안의 목록 거르기 기록 (테스트 있음)
    ├── use-exercise-session.ts # 재생 진행: 주의사항 → 단계별 안내 → 완료
    ├── speech.ts               # 음성 출력, 켜기·끄기, 잠시 멈춤
    ├── recognition.ts          # 음성 인식
    └── korean.ts               # 조사 고르기 (을/를) (테스트 있음)
```

데이터 모양은 `@yconic/shared-types`에서 가져온다. 사용자에게 넘어오는 콘텐츠는 필요한 칸만 고른 것이며(`PublishedExercise`),
올린 사람에게는 운영자 내부 메모를 뺀 모양(`MyContent`)이 간다.
