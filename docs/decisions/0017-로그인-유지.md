# 0017. 로그인 유지 (자동 로그인)

- 날짜: 2026-11-28
- 상태: 채택
- 결정자: Yconic

## 배경

로그인은 30일이 지나면 풀렸다. 쓰는 동안에도 날짜만 지나면 다시 로그인해야 했다.
화면을 보지 않고 쓰는 사람에게 로그인을 다시 하는 일은 번거롭다. 반대로 여럿이 함께 쓰는 기기에서는 로그인이 남아 있으면 곤란하다.
또 사용자 화면은 브라우저에 남은 로그인을 서버에 확인하지 않았다. 서버에서 끝난 로그인도 화면에는 로그인된 것처럼 보였다.

## 결정

1. **로그인 화면에 '로그인 유지' 체크 상자를 둔다. 처음 값은 켬이다.**
   - 켜면 로그인을 `localStorage`에 둔다. 브라우저를 닫아도 남는다.
   - 끄면 `sessionStorage`에 둔다. 탭이나 브라우저를 닫으면 로그아웃된다.
   - 구글 로그인, 이메일 로그인, 가입 모두에 적용한다.
2. **서버의 로그인 기간도 다르게 둔다** (`auth_sessions.remember`).
   - 유지: 30일. **쓰는 동안 남은 기간이 절반 아래로 내려가면 다시 30일로 늘린다.** 꾸준히 쓰는 사람은 다시 로그인하지 않는다. 30일 동안 한 번도 들어오지 않으면 풀린다.
   - 유지 안 함: 하루. 늘리지 않는다.
3. **화면은 들어올 때마다 서버에 로그인을 확인한다** (`GET /auth/session`).
   - 서버가 알려 준 만료 시각을 브라우저에 다시 적는다.
   - 서버에서 끝난 로그인(만료, 로그아웃, 비밀번호 바꿈)은 그 자리에서 지운다.
   - 서버에 연결하지 못하면 남은 로그인을 그대로 쓴다.

## 결과

- 좋은 점: 자기 기기에서는 로그인이 풀리지 않는다. 함께 쓰는 기기에서는 체크를 끄면 된다.
- 한계
  - 로그인 토큰은 브라우저 저장소에 둔다. 화면에 나쁜 스크립트가 들어오면 읽힐 수 있다 (지금까지와 같다).
  - 다른 기기의 로그인을 한꺼번에 끊는 화면은 없다.
- 나중에: 로그인한 기기 목록과 모두 로그아웃, 쿠키(HttpOnly)로 옮기기.
