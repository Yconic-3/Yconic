# 0011. 시안 D 네온 그린: 화면 구성과 이용 흐름

- 날짜: 2026-11-25
- 상태: 채택
- 결정자: Yconic

## 배경

새 디자인 자료 두 가지가 나왔다.

- **전체 화면**: 시안 D 네온 그린 웹, 17화면
- **이용 흐름**: 사용자 유형별로 첫 화면부터 목표까지 거치는 화면 순서
  - 흐름 A: 운동하기
  - 흐름 B: 콘텐츠 올리기
  - 흐름 C: 설정과 계정

색과 구성이 그동안의 화면과 다르다. 그동안의 화면은 노랑 강조, 세 줄 메뉴, 말하기와 검색창만 있는 시작 화면이었다.

## 결정

새 자료를 기준으로 사용자 화면의 구성을 바꾼다. 관리자 화면(`/admin`)은 그대로 둔다.

1. **색**
   - 강조색을 노랑에서 네온 그린(`#dcf35f`, 그라데이션)으로 바꾼다.
   - 하늘색은 보조 조작(로그인, 음성 안내 아이콘)에 그대로 쓴다.
2. **머리말**
   - 왼쪽에 로고 '소리벗'을 둔다.
   - 오른쪽에 '운동하기', '콘텐츠 올리기' 탭과 아이콘 버튼 셋을 둔다.

     | 아이콘 | 하는 일 |
     |---|---|
     | 로그인 / 내 계정 | 로그인 화면이나 내 계정으로 간다 |
     | 음성 안내 | 음성 안내를 켜고 끈다 |
     | 톱니 | 설정 창을 연다 |

   - 세 줄 메뉴는 없앤다.
3. **설정 창** (톱니, 또는 "설정"이라고 말하기)
   - 화면 위에 겹쳐 뜨는 창이다.
   - 들어 있는 것:
     - 음성 안내 켜기·끄기
     - 읽기 속도: 느리게·보통·빠르게
     - 부르면 듣기("소리벗")
     - 글자 크기: 보통·크게·아주 크게
     - 계정: 로그인 전에는 로그인, 로그인 후에는 내 강의 설정·내 계정·로그아웃
   - 글자 크기는 화면 전체를 1.15배·1.3배로 키운다.
4. **홈**: 가운데에 아래 차례로 둔다.
   - 현재 상태 배지 (예: "운동하기 · 로그인 전")
   - "어떤 운동을 할까요?"
   - 안내 상자 (앱이 방금 한 말)
   - 큰 「눌러서 말하기」
   - 말 대신 글로 입력
   - 운동 목록이 어디 있는지 알리는 한 줄
5. **다른 화면**은 두 열이다.
   - 왼쪽: 쪽 표시, 제목, 안내 상자("말하는 중" 표시, 내가 한 말), 그 화면의 내용
   - 오른쪽: '말로 하기' 패널 (눌러서 말하기, 말 대신 글로 입력)
   - 좁은 화면에서는 한 열이 되고, 말하기 버튼은 화면 아래에 붙는다.
6. **말 대신 글로 입력**: 검색창 대신 둔다. 쓴 말은 말한 것과 똑같이 처리한다 (예: "스쿼트 시작", "다음", "하체 운동 찾아줘").
7. **흐름 A · 운동하기**
   - 머리말의 '운동하기'나 "운동 목록"이라는 말로 **운동 고르기**(`/videos`)가 열린다. 전체 운동이 한 줄씩 나온다.
   - 부위는 "하체 운동 찾아줘"로 찾는다. 결과 화면 제목은 '하체 운동'이다.
   - 운동을 고르면 "○○ 안내를 시작할까요?"라고 묻는다. "네"나 "시작"이라고 하면 시작한다.
   - **시작 전**: 전체 단계 카드가 나온다 (지금 단계는 네온 그린 테두리).
   - **진행 중**: 위에 진행 막대(단계 이름과 'n / 전체'), 그 아래 지금 단계 카드가 나온다.
   - 화면 아래에 조작 막대(이전 단계 · 시작/멈춤 · 다음 단계 · 다시 듣기)를 둔다.
8. **흐름 B · 콘텐츠 올리기**
   - 로그인 전에 '콘텐츠 올리기'를 누르면 **저장된 계정으로 로그인** 화면이 먼저 나오고, 로그인하면 내 콘텐츠로 바로 간다.
   - 로그인 화면의 순서:
     1. 저장된 계정 한 개와 "○○님으로 로그인" 큰 버튼
     2. 다른 체험 계정
     3. 이메일·비밀번호 로그인 (접어 둠)
9. **흐름 C · 설정과 계정**
   - 내 강의는 강의 목록이 먼저 나온다.
     - 수강한 강의는 네온 그린으로 채운다.
     - 안 한 강의에는 '누르면 등록'을 붙인다.
   - 내 계정에는 계정, 내 강의, 올린 콘텐츠 수와 로그아웃이 있다.

## 디자인과 다르게 둔 것

- **운동 안내 화면의 동작 그림 자리에 영상을 둔다.**
  - 콘텐츠의 본체는 영상이다 (0002).
  - 일반 사용자도 함께 쓴다 (0007).
  - 영상이 없는 예시 운동은 "영상 없이 소리로 안내해요"를 보여 준다.
- **설정에 '부르면 듣기'를 더했다** (0009의 기능).
- **내 강의 아래에 '배운 동작(동작 하나씩)'을 남겼다.** 동작 단위 맞춤 안내의 바탕이다 (0008).
- **관리자 계정으로 로그인하면 설정 창의 계정 부분에 '관리자 화면'이 나온다.**

## 결과

- 세 가지 흐름(운동하기, 콘텐츠 올리기, 설정과 계정)을 버튼과 말 두 가지로 모두 따라갈 수 있다.
- 그전 요청으로 만든 세 줄 메뉴와 '모든 운동 영상' 화면은 이 구성으로 바뀐다.
  - '모든 운동 영상' 화면은 '운동 고르기'가 되었다. 주소 `/videos`는 그대로다.
