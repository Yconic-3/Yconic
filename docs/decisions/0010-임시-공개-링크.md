# 0010. 서버를 받기 전 임시 공개 링크

- 날짜: 2026-11-12
- 상태: 채택 (서버 배포 전까지)
- 결정자: Yconic

## 배경

팀원과 다른 사람이 소리벗을 직접 열어 보게 하고 싶다. 하지만 정식 서버(모두의 AI 실험실)는 아직 받지 못했다.
그동안은 내 컴퓨터에서 켠 사이트를 임시 https 주소로 열어 둔다.
https여야 하는 이유는 브라우저가 https에서만 마이크를 허용하기 때문이다.

## 결정

1. **Cloudflare 임시 터널(quick tunnel)로 연다.**
   - 계정 없이 `https://….trycloudflare.com` 주소를 받는다.
   - 내 컴퓨터와 `pnpm dev`가 켜져 있는 동안만 열린다.
   - 다시 켤 때마다 주소가 바뀐다.
2. **웹앱이 API와 AI 에이전트를 대신 연결한다** (`apps/web/next.config.ts`의 rewrites).
   - `/api/*`는 API(4000번)로, `/agent/*`는 에이전트(4100번)로 넘긴다.
   - 그래서 주소 하나로 화면, API, 에이전트, 영상을 모두 쓴다.
   - 영상 재생 주소의 기본값도 `/api`로 바꿨다(`API_PUBLIC_URL`).
   - 영상 올리기는 대신 연결하는 동안 520MB까지 받는다.
3. **공개용 웹앱은 따로 빌드해 3001번에서 켠다.**
   - `pnpm share`(또는 `공유하기.cmd`)가 다음을 한 번에 한다.
     - 공개용 웹앱 빌드(`.next-share`)
     - 3001번에서 켜기
     - 터널 열기
     - 주소 알려 주기
   - 개발용 웹앱(3000번)은 그대로 쓴다.
4. **공개 전 안전장치**
   - 저장소가 공개라 예시 관리자 계정의 비밀번호도 공개되어 있다.
     그래서 Cloudflare를 거쳐 온 로그인 요청(`cf-connecting-ip` 헤더)은 관리자 계정을 거절한다.
     관리자 화면은 이 컴퓨터(localhost)에서만 쓴다.
   - 공개용 화면의 체험 계정 목록에는 일반 회원만 보인다.
   - 하루 AI 사용 한도를 둔다 (`withDailyLimit`). 넘으면 각자 정해진 방식으로 돌아간다.

     | 쓰임 | 한도를 정하는 환경 변수 | 예시 값 | 한도를 넘으면 |
     |---|---|---|---|
     | 영상 분석 | `AI_DAILY_LIMIT_ANALYSIS` | 5 | 분석 작업이 실패로 끝나고 이유를 알린다 |
     | 맞춤 안내 | `AI_DAILY_LIMIT_GUIDES` | 100 | 규칙 안내로 돌아간다 |
     | 대화(에이전트) | `AI_DAILY_LIMIT` | 300 | 규칙 해석으로 돌아간다 |

   - 에이전트의 분당 요청 제한은 Cloudflare가 알려 주는 실제 접속 주소로 센다.
   - 남이 만든 영상은 공개하지 않는다. 시험에 쓴 스쿼트 영상은 공개를 중단했다.

## 결과

- 주소 하나만 보내면 누구나 휴대폰에서도 열 수 있다. 마이크, AI 대화, 맞춤 안내, 영상 올리기까지 모두 된다.
- 한계
  - 내 컴퓨터가 꺼지거나 잠들면 링크도 닫힌다.
  - 주소가 매번 바뀐다.
  - 모든 방문자가 같은 체험 회원 계정을 쓰므로, 내 동작과 올린 영상이 서로 보인다.
- 정식 서버를 받으면 고정 주소와 https 인증서로 배포하고, 이 방식은 시연용으로만 남긴다.
