## 2026-11-28 · Yconic (클라우드 서버에 올림)

- 뮤즈 클라우드 서버에 DB·API·AI 에이전트·웹앱을 올렸다. Vercel 주소(`https://soribeot-yconic.vercel.app`)가 이제 예시 데이터가 아니라 서버의 실제 데이터를 쓴다 (`docs/decisions/0014-클라우드-서버와-Vercel-연결.md`).
- `main`에 병합하면 Vercel만 자동으로 배포된다. **API나 공통 타입을 바꿨으면 서버도 업데이트해야 한다** (`docs/deploy-cloud.md`의 '코드 업데이트').
- 관리자 계정의 비밀번호는 서버에서 바꿨다. 예시 비밀번호로는 관리자 로그인이 안 된다. 필요한 사람은 Yconic에게 물어본다.
- 음성 대화를 빠르게 했다: 조작 명령은 AI 한 번, 짧은 조작·대답은 덜 기다리고 덜 끝난 말은 더 기다림, 답이 늦으면 맞장구 (`0019`). 화면 도구에 `say`가 생겼다.
- 로그인 화면에 '로그인 유지'를 넣었고(`0017`), 관리자 화면을 소리벗 색으로 바꿨다(`0018`). 관리자 화면에서는 `bg-blue-600`이 네온 그린으로 나온다.
- 로그인을 구글 계정과 이메일 가입으로 바꿨다. 공개 서버에서는 체험 계정이 보이지 않는다 (`docs/decisions/0016-회원가입과-구글-로그인.md`).
- 업체 프록시가 1MB보다 큰 요청을 막아서, 영상은 작은 조각으로 나눠 올리게 바꿨다 (`docs/decisions/0015-영상-나눠-올리기.md`).

## 2026-11-25 · Yconic (운동 중 대화와 묻고 기다리기)

- 회의 피드백 반영: 운동 중에는 "소리벗" 없이 말해도 되고 말을 끝까지 듣는다(1.3초 쉼). 앱이 말하는 중에 말하면 앱이 멈추고 듣는다. 앱 소리가 다시 들어와도 명령으로 오해하지 않는다.
- 단계가 끝나면 "넘어갈까요?" 묻고 기다린다(설정에서 끌 수 있음). 말로 화면을 바꿀 때도 묻는다. 운동이 끝나면 다음 운동을 권한다.
- 설명은 더 쉬운 말로. 다시 듣거나 "어려워요"라고 한 동작은 더 쉽게 안내한다 (마이그레이션 0005).
- Vercel 배포 준비: `docs/deploy-vercel.md` (Vercel 가입·연결은 직접).
- 자세한 내용: `docs/decisions/0012-운동-중-대화와-묻고-기다리기.md`

## 2026-11-12 · Yconic (실제 영상 분석과 동작 단위 맞춤 안내)

- **영상 분석이 진짜가 됐다.** 영상을 올리면 장면(ffmpeg)과 강사 말(faster-whisper)을 Claude가 보고, 단계와 음성 안내 초안을 만든다. 5분 영상에 약 1분 반 걸린다.
- **동작 단위 맞춤 안내.** 단계마다 동작(스쿼트, 팔굽혀펴기 …)이 붙는다. 회원이 "스쿼트 배웠어"라고 하거나, 강의를 등록하거나, 3번 끝까지 따라 하면 그 동작은 어느 영상에서든 짧게 안내한다. AI가 배운 용어로 사람마다 다시 쓴다.
- 실제 분석을 쓰려면 `apps/api/.env`에 `ANTHROPIC_API_KEY`, 그리고 ffmpeg·Python(faster-whisper)이 필요하다. 없으면 `VIDEO_ANALYZER=mock`.
- 테이블이 늘었다 (`account_movements`, `personalized_guides`, `segments.movements`). 받은 뒤 `pnpm db:migrate`.
- 자세한 내용: `docs/decisions/0008-실제-영상-분석과-동작-단위-맞춤-안내.md`
- **임시 공개 링크**: `pnpm dev`를 켠 채로 `pnpm share`(또는 `공유하기.cmd`)를 실행하면 누구나 열 수 있는 https 주소가 나온다. cloudflared가 필요하다 (`docs/decisions/0010-임시-공개-링크.md`)
- **강사 말과 안내가 겹치지 않게**: 음성 안내를 켜면 강사가 말하는 부분은 영상 소리를 끄고 맞춤 안내가 대신 말한다. 끄면 원래 영상 그대로. **"소리벗"이라고 부르면 듣는다.** (`docs/decisions/0009-강사-말-대신-맞춤-안내와-부르면-듣기.md`, 마이그레이션 0004)

## 2026-11-11 · Yconic (사용자 앱 + 관리자 웹 → 한 웹앱)

- **사용자 앱과 관리자 웹을 한 웹앱 `apps/web`으로 합쳤다.** `pnpm dev:web` 하나로 실행한다. 사용자 화면은 http://localhost:3000 , 관리자 화면은 http://localhost:3000/admin .

- 코드 위치: 사용자 화면 `apps/web/src/user`, 관리자 화면 `apps/web/src/admin`, 함께 쓰는 모의 백엔드 `apps/web/src/mock`. 서로의 화면 코드는 가져다 쓰지 않는다.
- `pnpm dev:admin`, `pnpm dev:user`는 없어졌다. 예전 브랜치에서 작업 중이면 main을 받은 뒤 위 경로로 옮겨 주세요.
- 결정 기록: `docs/decisions/0004-한-웹앱으로-합치기.md`
