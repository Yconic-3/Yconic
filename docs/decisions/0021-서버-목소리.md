# 0021. 서버 목소리 (TTS)

- 날짜: 2026-11-28
- 상태: 채택 (서버에 키를 넣으면 켜진다)
- 결정자: Yconic

## 배경

음성 안내를 브라우저에 든 음성(기기의 목소리)으로 읽어 왔다. 기기와 브라우저마다 목소리가 다르고 품질이 들쭉날쭉하다.
같은 서비스인데 휴대폰마다 다른 목소리가 나온다. 더 자연스럽고 늘 같은 목소리로 바꾸고 싶다.

## 결정

1. **서버가 글을 음성 파일로 만들어 주고, 화면은 그 파일을 재생한다.**
   - `POST /tts { text }` → `{ url }`. 주소는 `/media/tts/<글과 목소리의 해시>.mp3`다. 모양은 `packages/shared-types/src/tts.ts`.
   - 음성은 Google Cloud Text-to-Speech로 만든다. 키(`GOOGLE_TTS_API_KEY`)와 음성 이름(`TTS_VOICE`)은 API의 `.env`에 둔다. 키는 화면으로 나가지 않는다.
   - 키가 없으면 서버 목소리는 꺼져 있고(`GET /tts/config` → `enabled: false`), 화면은 예전처럼 기기의 목소리로 읽는다.
   - 음성을 만드는 부분은 함수 하나(`SpeechSynthesizer`)라서 다른 회사 것으로 바꾸기 쉽다.
2. **같은 글은 한 번만 만든다.**
   - 만든 파일을 서버 폴더(`storage/tts`)에 두고 다시 쓴다. 운동 안내 글처럼 여러 사람이 듣는 글은 처음 한 번만 만든다.
   - 30일 동안 다시 쓰이지 않은 파일은 지운다.
3. **화면은 문장마다 받아 차례로 재생한다** (`speech.ts`, `server-voice.ts`).
   - 한 문장을 읽는 동안 다음 문장을 미리 받는다. 문장 사이가 끊기지 않는다.
   - 말 속도는 재생 속도로 맞춘다. 속도마다 파일을 따로 만들지 않는다.
   - 맞장구("잠시만요.", "확인해 볼게요.")는 화면이 뜰 때 미리 받아 둔다.
   - 재생기는 하나만 두고, 사람이 화면을 처음 누를 때 깨워 둔다. 휴대폰 브라우저는 사람이 누른 뒤에 시작한 재생기만 소리를 내게 하기 때문이다.
4. **서버 목소리가 안 되면 기기의 목소리로 읽는다. 조용히 기다리게 하지 않는다.**
   - 서버가 2.5초 안에 주지 못하면 그 문장부터 기기의 목소리로 읽는다.
   - 꺼져 있거나, 한도를 넘었거나, 재생이 안 될 때도 같다.
   - 잇달아 세 번 실패하면 1분 동안 서버에 묻지 않는다.
5. **로그인 없이 쓰는 기능이라 한도를 둔다.** 남이 음성 만들기를 공짜로 가져다 쓰지 못하게 하고, 요금이 끝없이 늘지 않게 한다.
   - 한 번에 300자 (`TTS_MAX_CHARS`)
   - 한 곳(IP)에서 1분에 60번 (`TTS_PER_IP_PER_MINUTE`)
   - 하루에 새로 만드는 글자 3만 자 (`TTS_DAILY_CHARS`). 이미 만든 글은 세지 않는다. 한 달이면 약 90만 자다.
6. **함께 고친 것: 저장 폴더 전체를 공개하던 것을 영상과 음성 파일만 공개하게 바꿨다.**
   - 지금까지는 `storage` 전체가 `/media/`로 열려 있어서, 올리는 중인 영상 조각(`storage/uploads/<올리기 ID>`)도 주소를 알면 열렸다. 결정 0015에 "바깥에 공개하지 않는다"고 적은 것은 틀렸다.
   - 이제 `/media/videos/`와 `/media/tts/`만 연다.

## 결과

- 좋은 점: 기기가 달라도 같은 목소리로 읽는다. 서버 목소리가 안 될 때도 안내는 끊기지 않는다.
- 한계
  - 처음 듣는 글은 서버가 음성을 만드는 시간만큼 늦게 시작한다. 얼마나 늦는지는 키를 넣은 뒤에 재야 안다.
  - AI가 사람마다 다시 쓴 맞춤 안내와 대화의 답은 글이 매번 달라서 대부분 새로 만든다. 하루 한도를 먼저 쓴다.
  - 읽다가 서버 목소리에서 기기의 목소리로 넘어가면 중간에 목소리가 바뀐다.
  - 음성 파일 주소는 글을 아는 사람이 계산할 수 있다 (비밀이 아니다). 운동 안내 글은 공개된 글이라 문제가 되지 않지만, 개인적인 글을 읽히는 용도로는 쓰지 않는다.
  - 가격과 무료 한도는 Google의 가격표를 직접 확인해야 한다 (조사할 때 가격표 페이지를 읽지 못했다).
- 나중에: 콘텐츠를 공개할 때 안내 음성을 미리 만들어 두기, 설정에서 목소리 고르기, 음성 파일을 S3로 옮기기.
