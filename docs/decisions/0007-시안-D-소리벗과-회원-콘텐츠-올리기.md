# 0007. 시안 D(소리벗) 적용: 다크 고대비 화면, 회원 콘텐츠 올리기, 내 강의

- 날짜: 2026-11-12
- 상태: 채택
- 결정자: Yconic

## 배경

디자인 시안 D('시각장애인 맞춤형 운동 플랫폼', 앱·웹 두 버전)가 나왔다. 화면 디자인뿐 아니라 시스템도 바뀐다.

- **운동하기**와 **콘텐츠 올리기**를 한 앱에서 오간다 (소비·공급 통합).
  일반 회원도 운동 영상을 올리고, AI가 만든 음성 안내 초안을 확인해 검수를 요청한다.
- **내 강의**: 강사에게 배운 강의를 등록하면 그 동작은 짧게, 처음 하는 동작은 자세히 안내한다.

시안의 운동 화면에는 영상이 없지만, 일반 사용자도 함께 쓰므로 영상은 남긴다 (0002 그대로).

## 결정

1. **사용자 화면 디자인을 시안 D로 바꾼다.**
   - 이름은 **소리벗**이다. 바탕은 어두운 고대비(#0F1115)이다.
   - 노랑(#FFD23F)은 가장 중요한 조작과 '지금 여기'에, 하늘색(#4CC9F0)은 보조 조작과 초점에 쓴다.
   - 글꼴은 KoddiUD 온고딕(한국장애인개발원)이고, 기본 글자 크기는 20px이다. 글꼴 파일은 `apps/web/public/fonts`에 있다.
   - 넓은 화면은 본문과 음성 패널(마이크, 예시 말, 글 입력)의 두 열이다. 좁은 화면은 한 열이고 마이크가 화면 아래에 붙는다.
   - 대화 기록 대신 '방금 안내'와 '내가 한 말'을 보여 준다.
   - 음성 안내 켜기·끄기와 '읽기 잠시 멈춤'이 생긴다. 끄면 안내를 글로만 보여 주고, 운동 진행은 읽는 시간만큼 기다려 이어 간다.
   - 관리자 화면(`/admin`)의 디자인은 그대로다.
2. **로그인한 회원은 누구나 콘텐츠를 올릴 수 있다** (`/my/contents`, API `/me/...`, `packages/shared-types/src/creator-api.ts`).
   - 자기가 올린 영상·작업·콘텐츠만 보고 고친다. 남의 것은 404로 답한다.
   - 올린 사람이 고칠 수 있는 것은 단계별 음성 안내뿐이다. 구간 시각·순서는 운영자가 관리자 화면에서 고친다.
   - 검수를 요청하려면 "동작 설명이 정확하고 안전한지 확인했다"에 표시해야 한다. 시각 의존 표현("이렇게", "여기" 등)이 남아 있으면 요청을 막는다.
   - 승인·공개는 지금처럼 관리자 API의 승인권자만 한다. **자기 승인 금지(0003)는 그대로**다.
   - 감사 로그의 실행자 역할(`actor_role`)은 회원이면 비어 있다.
3. **AI 분석은 '화면에서만 전달되던 정보'도 찾는다** (`AccessibilityFinding`). 예를 들면 다음과 같은 것이다.
   - 동작 방향, 신체 위치
   - 읽히지 않은 화면 자막
   - 화면 타이머로만 나온 횟수

   올린 사람과 검수자에게 보여 준다. 지금은 모의 분석기가 분류별 예시를 돌려준다.
4. **내 강의** (`packages/shared-types/src/courses.ts`, API `GET/PUT /me/courses`, 테이블 `account_courses`).
   - 강의는 하체 기초, 코어, 상체 기초, 스트레칭·요가이다. 운동이 어느 강의에 속하는지는 분류와 꼬리표로 정한다.
   - 단계마다 **짧은 안내(`conciseGuide`)**를 둔다. 배운 강의의 운동이면 짧은 안내를 읽고, 그 밖에는 자세한 안내(`voiceGuide`)를 읽는다. 짧은 안내가 비어 있으면 자세한 안내를 읽는다.
   - 로그인하지 않았으면 모두 자세하게 안내한다.
   - 만들어 둔 음성 파일은 자세한 안내를 읽은 것이다. 그래서 짧은 안내는 브라우저 음성으로 읽는다.

## 설계 문서와 다른 점

- 설계 문서는 영상 업로드와 콘텐츠 제작을 관리자 웹의 일로 둔다. 이 결정으로 일반 회원도 올리고 검수를 요청한다.
  설계 문서의 원칙인 "AI가 만든 콘텐츠는 관리자 검수·승인 뒤에만 공개"는 그대로 지킨다.

## 결과

- 화면 주소가 늘었다. 모두 같은 틀(머리말 + 방금 안내 + 음성 패널) 안에 나온다.
  - 운동하기: `/`, `/exercises/[id]`
  - 계정·강의: `/account`, `/courses`
  - 콘텐츠 올리기: `/my/contents`, `/my/contents/new`, `/my/contents/[id]`
- 음성 명령이 늘었다.
  - 계정·화면 종류: "로그인", "로그아웃", "콘텐츠 올리기", "새 콘텐츠", "운동하기"
  - 음성 설정: "음성 안내 꺼/켜", "음성 멈춰", "이어 읽어"
  - 콘텐츠 올리기: "분석 시작", "미리 듣기", "검수 요청"
  - 내 강의: "하체 강의 들었어", "코어 강의 안 들었어"
- 마이그레이션 두 개가 늘었다.
  - `0001_member_uploads`: 감사 로그 역할 비우기 허용
  - `0002_learned_courses`: 짧은 안내 칸, 내 강의 테이블
- 다음 단계:
  - 실제 분석기로 '화면에서만 전달되던 정보' 찾기
  - 올린 사람에게 검수 결과 알림
  - 회원이 올린 콘텐츠의 신고·삭제 절차
