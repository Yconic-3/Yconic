# 관리자 화면 (/admin)

> 2026-11-11부터 사용자 화면과 한 웹앱(`apps/web`)으로 합쳤다 (`docs/decisions/0004`). 관리자 화면 주소는 `/admin`이다.
> 아래 구조의 `components/`, `lib/`는 `src/admin/` 아래에 있고, 페이지는 `src/app/admin/`에 있다. 모의 백엔드(`lib/api/mock/`)는 사용자 화면과 함께 쓰도록 `src/mock/`으로 옮겼다.

운동 **영상**을 올리고, AI가 나눈 동작 구간과 구간별 음성 안내를 영상을 보면서 검수·승인해서 사용자에게 공개하는 관리자 화면이다.
(설계 결정: `docs/decisions/0002-영상-중심-콘텐츠-모델.md`)

## 실행

```bash
pnpm install
```

```bash
pnpm dev:web
```

http://localhost:3000/admin 에서 열린다. 백엔드 없이 **모의 데이터 모드**로 동작하며,
로그인 화면에서 역할(편집자·승인권자·최고 관리자·조회자)을 골라 들어간다.

- 데이터는 브라우저 localStorage에, 올린 영상 파일은 IndexedDB에 저장된다. 새로 고쳐도 유지된다.
- 왼쪽 아래 "데이터 초기화"로 처음 상태로 되돌릴 수 있다.
- 예시 데이터 중 공개 운동 4개는 사용자 화면의 처음 목록이고, 검수 중·초안·수정 요청 예시 3개는 관리자 흐름 시연용이다. 예시 데이터에는 영상 파일이 없다. "▶ 시간만 재생"을 누르면 영상 없이 시간만 흘러 구간 안내를 확인할 수 있다. 실제 영상은 "새 AI 제작 요청"에서 올린다.
- 모의 분석기는 영상 내용을 보지 않고 **길이만으로** 준비 → 운동 → 휴식 → 마무리 구간을 나눈다. 파일 이름에 `fail`이 있으면 실패를 시연한다.

## 화면

| 경로 | 내용 |
| --- | --- |
| `/admin/login` | 역할 선택 로그인 (모의 모드) |
| `/admin` | 대시보드: 상태별 개수, 내가 처리할 콘텐츠, 진행 중 작업 |
| `/admin/jobs/new` | 영상 올리기 → 길이·해상도 확인 → 제작 요청 |
| `/admin/jobs` | AI 제작 작업 진행률, 실패 재시도, 완료된 초안 열기 |
| `/admin/contents` | 영상 목록, 상태 필터, 검색 |
| `/admin/contents/[id]` | 영상 플레이어 + 구간 타임라인 + 구간 편집 + 검사 결과 + 검수·승인·공개 |
| `/admin/audit` | 감사 로그 (최고 관리자) |

### 상세 화면에서 할 수 있는 것

- **사용자 경험 미리 듣기**: 제목·요약 → 주의사항 → 영상 재생 → 구간마다 안내, 사용자가 듣는 순서 그대로 한 번에 재생한다. "화면 가리기"를 켜면 영상이 가려져 소리만으로 이해되는지 확인할 수 있다. Esc로 멈춘다.
- 타임라인의 구간을 누르면 영상이 그 시각으로 이동하고 해당 구간 편집 칸으로 스크롤한다.
- 타임라인의 흰 경계선을 끌어 구간 시작·끝을 조절한다. 맞닿은 두 구간은 함께 움직인다. 경계선을 Tab으로 고른 뒤 방향키로 1초씩(Shift 0.1초) 옮길 수도 있다.
- 영상을 원하는 곳에 멈추고 "현재" 버튼으로 구간의 시작·끝을 잡거나, "현재 시각에서 나누기"로 구간을 둘로 나눈다.
- "▶ 구간 재생"은 그 구간부터 재생하면서 안내문을 브라우저 음성으로 읽는다. "재생 중 구간 안내"를 켜 두면 재생 중 구간이 바뀔 때마다 읽는다.
- **영상 교체**: 구간은 그대로 두고 영상만 바꾼다. 길이가 다르면 검사 결과가 알려 준다.
- **다시 분석**: 현재 영상을 다시 분석해 구간과 안내문을 새 결과로 바꾼다. 분석 중에는 수정·검수 요청이 잠긴다.
- 검사 결과: 구간이 영상 길이를 넘거나 겹침(오류), 요약 없음(오류), 안내문을 읽는 시간이 구간보다 김(경고), 시각 의존 표현(경고), 음성 파일 미생성·재생성 필요(경고). 음성이 없는 구간이 있어도 공개는 할 수 있다.

### 단축키 (입력 칸 밖에서)

| 키 | 동작 |
| --- | --- |
| Space | 재생 / 정지 |
| ← / → | 5초 이동 (Shift: 1초) |
| N / P | 다음 / 이전 구간으로 |
| L | 지금 구간 안내 듣기 |
| S | 지금 시각에서 구간 나누기 |
| [ / ] | 지금 구간의 시작 / 끝을 지금 시각으로 |
| Esc | 사용자 경험 미리 듣기 멈추기 |

## 구조

```
src/
├── app/                      # Next.js 페이지 (모두 클라이언트 컴포넌트)
├── components/
│   ├── video-player.tsx      # 플레이어 + 구간 타임라인 (경계 끌기, 영상 없을 때 시간만 재생)
│   ├── segment-editor.tsx    # 구간 편집 (시각, 안내문, 음성 생성, 재생)
│   ├── video-tools.tsx       # 영상 교체, 다시 분석
│   ├── content-editor.tsx    # 제목·요약·분류 등 기본 정보
│   └── content-actions.tsx   # 검수 요청·승인·공개 (화면 안 확인)
└── lib/
    ├── api/
    │   ├── admin-api.ts        # AdminApi 인터페이스 (화면은 이것만 사용)
    │   ├── http-admin-api.ts   # 백엔드 HTTP 구현 (api 준비 후 사용)
    │   └── mock/
    │       ├── mock-admin-api.ts  # 모의 백엔드 (권한·상태 전이 검증 포함)
    │       ├── mock-analyzer.ts   # VideoAnalyzer 인터페이스 + 길이 기반 모의 분석기
    │       ├── video-store.ts     # VideoStore 인터페이스 + IndexedDB 구현
    │       └── seed.ts            # 예시 데이터
    ├── timeline.ts   # 구간 경계 계산, 끌기·나누기·구간 이동 (테스트 있음)
    ├── video.ts      # 영상 메타데이터 읽기, 타임코드 변환
    ├── speech.ts     # 브라우저 음성 합성 (미리 듣기)
    ├── session.tsx   # 로그인 상태와 AdminApi 제공
    └── use-async.ts  # 데이터 로딩·폴링 훅
```

데이터 모양, 권한표, 상태 전이, 검사 규칙, 분석 결과 형식은 `@yconic/shared-types`에서 가져온다.
모의 구현도 같은 규칙으로 거절하므로, 버튼을 숨기는 것과 별개로 실제 요청이 막히는지 확인할 수 있다.

## 다른 영역과의 접점

| 담당 | 구현할 것 | 기준 |
| --- | --- | --- |
| 백엔드 `apps/api` | 영상 업로드·재생 주소, 콘텐츠·작업·감사 로그 엔드포인트 | `packages/shared-types/src/admin-api.ts` 주석 |
| 워커 `apps/content-worker` | 실제 영상 분석 → `VideoAnalysisResult`, 구간별 TTS 생성 | `packages/shared-types/src/analysis.ts` |
| 사용자 화면 `src/user` | `PUBLISHED` 콘텐츠의 영상을 재생하며 구간 시작 시각에 `tts.audioUrl` 재생 | `packages/shared-types/src/exercise.ts` |

### 백엔드 연결

`.env.example`을 `.env.local`로 복사하고 모드를 바꾼다.

```
NEXT_PUBLIC_ADMIN_API_MODE=http
NEXT_PUBLIC_API_BASE_URL=http://localhost:4000
```

인증 방식이 정해지면 `http-admin-api.ts`의 토큰 전달 부분과 로그인 화면을 바꾼다.

## 테스트

```bash
pnpm --filter @yconic/web test
```

모의 구현의 권한 검사, 영상 업로드, 검수 흐름, 제작 작업 진행, 분석기 구간 나누기, 음성 생성을 검증한다.
