# 0018. 관리자 화면도 소리벗 디자인으로

- 날짜: 2026-11-28
- 상태: 채택
- 결정자: Yconic

## 배경

사용자 화면은 시안 D 네온 그린(다크 고대비)인데, 관리자 화면은 밝은 바탕에 파란색을 쓰는 다른 모습이었다. 이름도 'Yconic 관리자'였다.
같은 서비스인데 화면을 오갈 때마다 다른 사이트처럼 보였다.

## 결정

1. **관리자 화면도 사용자 화면과 같은 색·글꼴을 쓴다** (결정 0011의 색 토큰, KoddiUD 온고딕).
2. **화면 코드는 고치지 않고 색 이름의 값만 바꿔 끼운다.**
   - 관리자 화면의 코드는 `bg-white`, `text-slate-600`, `bg-blue-600`처럼 Tailwind 기본 색 이름으로 짜여 있다 (약 3,000줄).
   - Tailwind의 색은 CSS 변수라서, `apps/web/src/app/globals.css`의 `.admin-root` 안에서만 변수 값을 바꾼다.
   - white → 패널, slate → 어두운 바탕 위의 회색 단계, blue → 네온 그린, amber → 주의, red → 위험, green → 완료, emerald → 하늘색.
   - 그래서 관리자 화면에서 `text-white`는 "밝은 버튼 위의 어두운 글자"다. 검은 영상 위의 흰 글자는 `text-ink`를 쓴다.
3. **모양은 공용 부품에서만 맞춘다** (`apps/web/src/admin/components/ui.tsx`, `app-shell.tsx`).
   - 버튼·카드·입력칸의 모서리를 둥글게 하고 테두리를 굵게 한다. 주 버튼은 사용자 화면과 같은 네온 그린 그라데이션이다.
   - 왼쪽 메뉴 위에 소리벗 로고와 이름, '관리자' 표시를 둔다. 이름은 '소리벗 관리자'로 바꾼다.
4. **관리자 화면은 화면을 보고 쓰는 사람의 작업 도구라서 글자 크기와 촘촘함은 그대로 둔다.** 사용자 화면처럼 큰 글자·큰 버튼으로 바꾸지 않는다.

## 결과

- 좋은 점: 두 화면이 한 서비스로 보인다. 코드 변경이 작아 기능이 바뀔 위험이 낮다. 색을 바꿀 곳이 한 군데다.
- 한계
  - 색 이름과 실제 색이 다르다 (`bg-blue-600`이 네온 그린). 관리자 화면을 고치는 사람은 `globals.css`의 설명을 먼저 읽어야 한다.
  - 관리자 화면에서 새 Tailwind 색(예: `teal`, `blue-950`)을 쓰면 바뀌지 않은 원래 색이 나온다. 쓰기 전에 `.admin-root`에 값을 더한다.
- 나중에: 관리자 화면의 색 이름을 사용자 화면의 토큰 이름(`bg-panel`, `text-ink-2`, `bg-accent`)으로 차츰 바꾼다.
