# 0006. 사용자 AI 에이전트 (말로 운동 찾기·조작)

- 날짜: 2026-11-11
- 상태: 채택 (backend-mcp는 나중에)
- 결정자: Yconic

## 배경

사용자 화면은 사용자의 말을 키워드 규칙(`apps/web/src/user/lib/intent.ts`)으로 해석했다.
"무릎에 무리 없는 하체 운동 있어?", "그거 할래"처럼 자연스러운 말이나 앞 대화를 이어 받는 말은 알아듣지 못했다.
설계 문서 3장의 사용자 AI 에이전트(User Agent)를 만들어 화면(프론트엔드)과 백엔드 사이를 잇는다.

## 결정

1. **에이전트는 별도 앱 `apps/user-agent` (포트 4100)** 로 둔다 (설계 문서 2장).
   - 화면이 `POST /chat`으로 말·앞선 대화·지금 화면 상태를 보내면, 에이전트가 답할 말과 할 일(`AgentAction`)을 돌려준다.
   - 형식은 `packages/shared-types/src/agent.ts`.
2. **AI 모델은 Claude** (`claude-opus-5-5`, 생각 깊이 `low`).
   - 연결·대체 모델·사용량 기록은 공통 AI Core `packages/ai-common`에 둔다. 관리자 에이전트도 이것을 쓴다.
   - 거절(refusal)되면 Anthropic이 권하는 다른 모델로 한 번 더 돌린다 (`fallbacks: "default"`).
   - 모델과 깊이는 `AI_MODEL`, `AI_EFFORT`로 바꿀 수 있다.
3. **에이전트는 데이터베이스를 만지지 않는다.** 운동 정보는 백엔드 API의 사용자 API(`GET /exercises`)로만 가져온다.
   그래서 공개 중인 운동만 보고, 승인 전 콘텐츠나 관리자 메모는 볼 수 없다 (설계 문서 3장 지식 접근 정책).
4. **에이전트는 화면을 직접 바꾸지 않는다.** 도구는 두 가지다.
   - 정보 도구: 운동 찾기, 운동 자세히 보기.
   - 화면 도구: 운동 열기, 재생 조작(시작·멈춤·다음·이전·다시·중단), 말 속도, 화면 이동.
   화면 도구는 할 일만 모아 돌려주고, 실행은 화면이 한다. 없는 운동 id나 운동 화면이 아닐 때의 재생 조작은 에이전트가 막는다.
5. **키가 없거나 에이전트가 꺼져 있어도 앱은 그대로 쓸 수 있다.** 화면은 에이전트가 답하지 못하면 예전 규칙 기반 해석으로 처리한다
   (설계 문서 10장 "음성 기능이 동작하지 않아도 이용할 수 있어야 한다").
6. **위험 신호와 운동 중 짧은 조작은 화면이 바로 처리한다.**
   - 통증·어지럼 같은 위험 신호는 네트워크를 기다리지 않고 바로 멈춘다.
   - 운동 화면의 "다음", "멈춰"처럼 8자 이하 조작도 운동 흐름이 끊기지 않게 바로 처리한다.
   - 나머지 말은 에이전트가 맡는다.
7. 로그인 없이 쓰는 화면이라 **IP마다 1분 요청 수를 제한**한다 (`AGENT_RATE_LIMIT`, 기본 30). 허용한 웹앱 주소만 부를 수 있다 (CORS).

## 임시로 정한 것 (설계 문서와 다름)

- **backend-mcp 없이** 에이전트가 백엔드 API를 HTTP로 직접 부른다.
  설계 문서는 에이전트가 MCP 서버(`apps/backend-mcp`)를 거쳐 백엔드를 부르게 한다.
  지금 사용자 에이전트가 쓰는 백엔드 기능은 공개 운동 읽기 하나뿐이라 MCP의 이점이 작다.
  관리자 에이전트를 만들 때 backend-mcp를 만들고 이 부분(`apps/user-agent/src/backend.ts`)을 MCP 호출로 바꾼다.
- 운동 진행 상태(세션)는 아직 화면이 관리한다. 백엔드에 세션이 생기면 재생 조작도 백엔드 도구로 옮긴다 (설계 문서 3장 "운동 상태 관리").
- 대화 기록은 화면이 최근 말을 보내 주는 방식이다. 서버에 저장하지 않는다.

## 결과

- 사용자는 정해진 명령어를 몰라도 말로 운동을 찾고, 묻고, 고르고, 조작할 수 있다.
- 실행은 `pnpm dev:agent`. AI를 켜려면 `apps/user-agent/.env`에 `ANTHROPIC_API_KEY`를 넣는다. 키는 커밋하지 않는다.
- 테스트는 실제 Claude 대신 정해 둔 응답을 내는 가짜 모델로 돌린다. 그래서 CI에 키가 필요 없다.
  실제 Claude로 답의 품질을 확인하는 일은 키를 넣은 뒤에 따로 한다.
